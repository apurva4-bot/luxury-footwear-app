# Luxury Footwear Store

A full-stack women's luxury footwear e-commerce web application.

## About the Project

Luxury Footwear Store is a web-based e-commerce application designed for women's luxury footwear. The project provides a modern shopping experience with a frontend interface and a backend server for handling application functionality.

## Features

- Women's luxury footwear catalog
- Product browsing
- Product details
- Responsive user interface
- Backend API
- Database integration
- Shopping and order-related functionality
- Modern React-based frontend
- Node.js backend

## Tech Stack

### Frontend
- React
- Vite
- JavaScript
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB
